# D2 Diagrams

PiMD + PiDraw renders D2 diagrams with their native layout engine.

## Simple Architecture

```d2 title="Service Architecture"
api -> db: reads/writes
api -> cache: caches
api -> search: indexes
web -> api: HTTP
```

## Network Topology

```d2
cloud "AWS" {
    vpc "Main VPC" {
        subnet "Public" {
            lb: Load Balancer
            bastion: Bastion Host
        }
        subnet "Private" {
            app: Application Server
            cache: Redis Cluster
        }
        subnet "Data" {
            db: PostgreSQL
            warehouse: Data Warehouse
        }
    }
    dns: Route53
}

internet -> dns
dns -> lb
lb -> app
app -> cache
app -> db
app -> warehouse
```
